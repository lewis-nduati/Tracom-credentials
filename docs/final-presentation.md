# Slide 2: Project Identity

## Project Name

TRACOM Digital Credentials

## One-Sentence Product Description

TRACOM Digital Credentials is a blockchain-powered credential platform built with Andamio that enables educational institutions to issue verifiable digital credentials and allows employers and other third parties to independently verify them on Cardano.

# Slide 3: What the Product Does

## Who is the user?

Educational institutions  
Training providers  
Students  
Employers  

## What can users do?

Institutions can create and manage learning experiences that lead to blockchain-backed credentials.

Learners can enroll in courses, complete learning activities, and receive digital credentials.

Employers and third parties can independently verify credentials without relying on the issuing institution.

## Value

Tamper-resistant digital credentials

Independent credential verification

Learner ownership of digital records

Transparent credential history on Cardano

Institutional deployment support

## Deployment

TRACOM provides institutions with a pathway to deploy blockchain-based credential systems using Andamio and Cardano infrastructure.

Development and testing were completed on Cardano Preprod before migrating the application to Mainnet.

# Slide 5: Product Workflow

TRACOM enables institutions to issue verifiable credentials through a simple workflow.

Institution creates learning content.

Learner enrolls in a course.

Learner completes course requirements.

Credential is issued.

Credential can be verified independently using Cardano.

The current submission demonstrates the complete credential lifecycle workflow and production deployment.

## Institutional Deployment

Organizations can engage TRACOM for deployment planning, infrastructure configuration, and credential strategy consultation.

# Cardano Pie: Mainnet Functionality & Institutional Deployment

TRACOM Digital Credentials was developed using the Andamio platform and successfully migrated from Cardano Preprod to Cardano Mainnet.

The live application demonstrates:

Cardano Mainnet configuration

Mainnet Andamio Gateway integration

Mainnet Access Token Policy configuration

Wallet authentication against the Mainnet environment

Production deployment using the Mainnet configuration

Institutional deployment pathway through TRACOM consulting services

Development and testing were completed on Cardano Preprod before production migration to Mainnet.

Because Preprod and Mainnet are separate blockchain environments, the demonstration focuses on the successfully migrated Mainnet application rather than the original test data created during development.
