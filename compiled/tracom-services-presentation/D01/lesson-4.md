# What we built and what is next

Three full courses are compiled and ready: Introduction to Blockchain, POS Developer Fundamentals, and Secure Payments and Cybersecurity. Complete curricula, written for junior developers entering Kenya's fintech industry.

The student flow covers the full journey: landing page, sign-in, wallet connection, access token minting, course enrollment, lesson view, assignment submission, credential claim. The interface is designed to look like a professional institutional product.

The stack is Next.js, TypeScript, the Andamio protocol, and MeshJS for Cardano wallet integration.

One thing is still unresolved: a bug in the access token flow that allows multiple tokens to be minted in the same session. Once that is fixed, the full flow is ready for pilot students.

After the pilot comes the pioneer programme: a small cohort of real Tracom Academy students earning real credentials for completing real coursework.

The foundation is solid.
