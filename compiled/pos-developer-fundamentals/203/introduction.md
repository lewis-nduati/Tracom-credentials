# APIs and the Integration Layer

POS integration is, at its core, API integration. The terminal and the gateway communicate through APIs. Your application communicates with both through APIs. Every piece of data — the transaction amount, the approval code, the response message — travels as structured text across these interfaces.

This module teaches you how to read an API specification, understand exactly what your code must send and what it will receive back, and use a sandbox environment to test your integration without moving real money.

If you have never worked with payment APIs before, this module is the foundation everything else builds on. If you have worked with other APIs, this module will show you what makes payment APIs different — and more demanding — than most.
