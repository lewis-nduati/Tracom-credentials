# Designing a POS Integration

You have seen the hardware, understood the money rail, and learned how to read an API spec. This module puts all of it together into a system design.

Good integration design is not about writing clever code. It is about anticipating what goes wrong and deciding in advance how your system will behave when it does. Networks fail. Responses get lost. Customers tap their card twice. Your design must handle all of these before you write a single line of implementation code.

The assignment at the end of this module produces your architecture document — the design you will build during the capstone project. A reviewer will use it to confirm that you understand the system before you are asked to build it.
