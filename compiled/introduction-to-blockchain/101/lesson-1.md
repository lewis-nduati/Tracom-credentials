# How a Blockchain Works

 A blockchain is a shared, permanent record of transactions. Unlike a regular database controlled by one company, a blockchain is maintained by

  thousands of computers simultaneously. No single person or organization controls it.

  Each "block" contains a set of transactions and a reference to the block before it — forming a chain. Once a block is added, it cannot be

  altered without changing every block that came after it. This makes the record tamper-evident.

  Key properties:

  Decentralized — no single point of control or failure

  Immutable — records cannot be changed once confirmed

  Transparent — anyone can verify transactions

  Permissionless — anyone can participate without approval
