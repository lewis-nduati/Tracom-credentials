# Encryption and Tokenization

Module 301 identified where attackers can intercept card data in transit and at rest. This module covers the two mechanisms that make intercepted data useless: encryption and tokenization.

Encryption scrambles data so that only a system with the correct key can read it. Tokenization replaces sensitive data with a reference that means nothing outside the system that issued it. Together, they are the reason a well-built POS integration can be breached without the attacker gaining anything they can use.

These are not advanced security topics. They are the baseline. Every production POS integration uses both. By the end of this module you will understand exactly what each one protects, where each one applies, and how to verify that your integration is using them correctly.
