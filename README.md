# Tracom Credentials

Blockchain credentialing infrastructure for Tracom Academy — built on [Andamio](https://www.andamio.io/)

## Overview

Tracom Academy is Kenya's leading payments and software training institution. This project integrates Andamio's on-chain credentialing system into Tracom's existing course infrastructure.

Students complete courses, submit evidence, and receive verifiable credentials issued on the Cardano blockchain — credentials they own, carry, and use as access keys to real opportunities.

## The Problem

Tracom has no existing credentialing system. Students complete courses but walk away with nothing verifiable, portable, or independently trustworthy. This project fixes that.

## What This Builds

- Verifiable credentials for Kenyan students — proof of what you know, not just proof you attended
- On-chain certificates owned by the student, not locked in an institution's database
- Simple enough for everyday users, trustworthy enough for employers
